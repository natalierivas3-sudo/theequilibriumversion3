# The Equilibrium · v58

Student wellness hub for UT Austin and Austin: free and low-cost ways to rest, move, study, connect, and find support.

This is the v58 draft. Compared with Test version 57 it adds:

- A Calm me section with five choices up front and a short check-in (a 1–5 regulation scale; level 5 shows crisis support and a breathing guide first).
- A Coping skills page with 10 quick tools adapted from DBT, before/after ratings, and "My kit".
- Study spots map inside "Find a study spot", sorted closest first, with off-campus coffee shops.
- Smarter search, category buttons in Resources, accessibility and contrast fixes, and link previews for sharing.

## Run it

It's a static site. Open `index.html`, or turn on GitHub Pages (Settings → Pages → Deploy from branch → `main` / root).

Live at https://natalierivas3-sudo.github.io/theequilibriumversion3/. The link preview tags in `index.html` and `SITE_URL` in `v58.js` point there.
